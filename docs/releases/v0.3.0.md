# Solve2Ship Skills v0.3.0 / 价格就绪检查与独立容器环境

The optional headless bridge now checks the configured model's price readiness
before submitting new paid-capable operations. It reports the engine's active
review version and UTC validity window. Missing, expired, not-yet-valid, malformed
or mismatched review evidence prevents submission; the helper neither renews a
review nor changes authorization or accounting.

New paid operations require STS v0.16+ pricing status. Supported read-only routes,
cancellation, deterministic operator-review finals and saved successful receipts
remain usable without new model calls. The installed skill includes the price
review procedure and English/Chinese messages for recovery. It keeps the existing
request journal and no-replay rules.

The runtime guide documents Colima + Docker Engine/CLI on Apple Silicon macOS and
Docker Engine on Linux. Docker Desktop.app is not required. Installing Compose or
starting an Engine does not replace STS candidate-isolation acceptance; STS v0.16
does not ship a Compose application stack.

Validation: 37 stdlib tests, including 26 local HTTP protocol tests; deterministic
ZIP/checksum/allowlist and non-overwriting installation checks. These are workflow
and packaging checks, not evidence of model quality or optimization gains. No
third-party dependency, model key, runtime image or private pricing file is bundled.

An independent unpacked v0.3 installation was also checked against the local STS
v0.16 engine: the actual expired price review was returned and paid preflight
refused. Verification enforced GET-only transport; usage and service allowances
were unchanged, with zero new model calls. This proves that readiness path only,
not a new business-task optimization result.

## 简体中文

无前端连接工具现在会在提交新的付费相关操作前检查已配置模型的价格就绪状态，并展示
引擎当前审核版本及 UTC 有效期。价格缺失、过期、未生效、损坏或不匹配时停止提交；
工具不会自动续期，也不会修改预算授权或历史费用。

新的付费操作需 STS v0.16+。旧版支持的只读接口、取消、确定性方案的操作者最终复核、
历史成功回执恢复仍可使用且不新增模型调用。安装包附带价格复核步骤和中英双语恢复
提示，继续遵守持久操作编号及不自动重放规则。

运行环境说明支持 Apple Silicon macOS 的 Colima + Docker Engine/CLI 以及 Linux 的
Docker Engine，不需要 Docker Desktop.app。安装 Compose 或启动引擎不代表通过候选
隔离验收；STS v0.16 未附带 Compose 应用栈。

验证包含 37 项标准库测试，其中 26 项为本机 HTTP 协议测试，以及确定性 ZIP、校验清单、
文件白名单和不覆盖安装检查。这些不代表模型质量或优化收益。安装包不含第三方依赖、
模型密钥、镜像或私有价格文件。

仓库外解压的 v0.3 安装包也已连接本机 STS v0.16：实际过期价格被正确展示，付费前置
检查拒绝执行。验证通道强制仅允许 GET，历史费用与服务预留额度不变，零新增模型
调用。这是价格就绪路径的证据，不是新增业务任务的优化结果。
