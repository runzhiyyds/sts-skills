# Solve2Ship Skills v0.1.0

## English

First installable Goal-to-Service skill preview for local coding agents. Start with
business language and samples; compare executable approaches, record evidence and
budgets, iterate conservatively and verify an independent local service. No frontend
is required. Includes English/Chinese guides, synthetic example, license/citation,
non-overwriting installer and deterministic source-only installation ZIP.

11 helper tests and official skill metadata validation passed. An independent
forward test compared rules and an isolated Python script on six common unlabeled
cases: 12 actual outputs, one disagreement, zero paid calls. A standalone service
draft passed six HTTP equivalence checks plus malformed/cross-origin rejection.
Four final inputs stayed sealed; semantic quality/final winner remains unaccepted.
This used the already approved STS Docker runtime/trusted serving template. The skill
is guidance and evidence tooling, not a bundled execution engine, model or sandbox.
LangGraph/Dify are adapter-selection guidance, not tested runtime integrations.

Package checksums establish file integrity, not future agent correctness. Source
and SHA256 checksums are published; no runtime binary, key, dataset of real users,
process log or cloud deployment is included. Hosted CI availability is separate
from local evidence. On 2026-11-09 the account lock was cleared, the runner was
pinned to Ubuntu24.04, and hosted helper/package checks passed on commit367c9f0.
