# Contributing / 参与贡献

Start from a concrete user goal or demonstrated failure. Keep instructions concise,
progressive and understandable to nontechnical users. Proposals and framework
suggestions must not be marked implemented until exercised.

Run `python3 -m unittest discover -s tests -v` and `python3 scripts/package_skill.py`.
Describe actual behavior, evidence source and remaining limits. Keep fixtures
separate from model/runtime acceptance. Generated code must not execute on the host.
No credentials, user datasets, databases, process logs or model/runtime archives in PRs.
Preserve LICENSE/NOTICE and review third-party obligations before adoption.

中文：欢迎围绕真实目标或已观察失败提交小而可验收的改动。区分规划、协议测试和真实
执行证据，避免冗长通用规则或夸大能力。不要提交密钥、用户数据、本机状态或开发日志。
