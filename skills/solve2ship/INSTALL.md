# Install / 安装

Copy this entire solve2ship/ folder into the skill directory supported by your local
agent, then reload skills/restart that agent. For Codex the usual directory is
~/.codex/skills; for Claude Code it is ~/.claude/skills. Verify your host's current
support and preserve any different existing skill before an upgrade. No API key or
paid account is needed to install; actual task execution may need approved resources.

将整个 solve2ship/ 文件夹放入本地 Agent 支持的技能目录，再重新加载/重启。Codex 通常
使用 ~/.codex/skills，Claude Code 通常使用 ~/.claude/skills；以宿主当前支持为准，升级
前保留已有不同版本。安装无需密钥或付费账号，实际执行任务可能需要另行授权的资源。

Start / 开始：Use $solve2ship. Here are my examples and the outcome I want.
中文：使用 $solve2ship。这里是我的样本和期望，请比较方案并交付本地可用服务。
